ACTV Live

GitHub ↗

Portale web per il trasporto pubblico veneziano ACTV con tracciamento veicoli in tempo reale, pianificazione percorsi e orari GTFS.

PHP 8.4 Vanilla JS Leaflet.js MySQL GTFS PWA

Panoramica

ACTV Live nasce dalla necessità di avere informazioni aggiornate e affidabili sul trasporto pubblico di Venezia. Il portale integra i dati GTFS statici (fermate, linee, orari) con le API in tempo reale di ACTV per mostrare la posizione dei mezzi sulla mappa, le previsioni di arrivo alle fermate e i percorsi ottimali con cambi.

Architettura

L'applicazione utilizza un'architettura PHP MVC custom senza framework: un router centralizzato smista le richieste ai controller, che a loro volta caricano i modelli e le viste. Il frontend è in JavaScript puro con Leaflet.js per le mappe interattive e Bootstrap 5 per l'interfaccia. I dati GTFS vengono parsati dal feed ZIP ufficiale e cachati come file JSON multi-livello per performance ottimali.

Sfide Implementative

  • Day offset: gestione dei trip che attraversano la mezzanotte, con orari oltre le 24:00 nello standard GTFS
  • Real-time matching: sincronizzazione tra i blob delle API real-time e gli ID statici del database GTFS (processo "GTFS Identify")
  • Route Planner: algoritmo di calcolo percorsi con trasferimenti singoli basato esclusivamente sui file JSON cachati, senza query al database
  • PWA offline: Service Worker con strategia network-first e pre-cache selettivo dei dati GTFS
  • Timing points: logica di sincronizzazione per stimare la posizione dei veicoli tra un punto di timing e il successivo

Route Planner

GitHub ↗

Applicazione web per la pianificazione di percorsi escursionistici con mappe topografiche OSM, routing locale Valhalla e funzionalità di export complete.

Vanilla JS OpenLayers Docker Valhalla Node.js PWA

Panoramica

Progettato per gli amanti dell'escursionismo, Route Planner permette di tracciare itinerari su mappe topografiche OpenStreetMap con calcolo automatico di distanze, dislivelli positivi e negativi, e tempi stimati. Ogni percorso può essere suddiviso automaticamente per giornata tramite i "punti notte".

Architettura

L'applicazione si compone di 4 container Docker: il frontend (Vanilla JS + OpenLayers + nginx), un proxy di routing Node.js verso Valhalla locale con fallback configurabili, il motore Valhalla con tile OSM montati da volume, e un export service (Node.js + Puppeteer) per la generazione di PDF e PNG.

Sfide Implementative

  • Routing offline: download automatico di regioni Geofabrik con build dei tile Valhalla direttamente dall'interfaccia web
  • Export multi-formato: generazione GPX completo e split per giorni, PNG ad alta risoluzione e PDF con Puppeteer headless
  • Mappe offline: download e cache di tile raster in IndexedDB per uso senza connessione, con switch online/offline
  • Dati elevazione DEM: integrazione di dati altimetrici SRTM per il calcolo preciso dei dislivelli e il grafico altimetrico
  • Indicazioni turn-by-turn: istruzioni dettagliate con possibilità di aggiungere note personalizzate ad ogni punto

TotalCMD-MP

GitHub ↗

File manager dual-panel multipiattaforma ispirato a Total Commander. Costruito con Tauri v2, React e Rust per performance native.

Tauri v2 React TypeScript Rust Tailwind

Panoramica

Reimplementazione moderna del classico Total Commander come applicazione desktop multipiattaforma (Windows, macOS, Linux). L'obiettivo è offrire la stessa produttività del gestore file a doppio pannello con un'interfaccia aggiornata e supporto FTP/SFTP.

Architettura

Il backend Rust di Tauri v2 gestisce le operazioni su filesystem con performance native, mentre il frontend React/TypeScript con Zustand per lo state management offre un'interfaccia reattiva. Il design usa un tema dark ispirato a Catppuccin con pannelli ridimensionabili.

Sfide Implementative

  • Navigazione da tastiera completa: riproduzione fedele delle scorciatoie di Total Commander (F3-F8, Space, Insert, Numpad *)
  • Dual-panel con tab: gestione dello stato indipendente per ogni pannello e ogni tab, con splitter ridimensionabile
  • Operazioni file cross-panel: Copy (F5), Move (F6), Delete (F8) tra pannelli con feedback visivo
  • Breadcrumb interattivi: click per navigare, doppio click per editare il percorso manualmente

Cronometro

GitHub ↗

Cronometro fullscreen con interfaccia minimalista, precisione al centesimo di secondo e design pensato per massima leggibilità.

React TypeScript Vite Tailwind

Panoramica

Applicazione cronometro a schermo intero pensata per essere chiara e leggibile anche a distanza. Il design scuro con font industriali ricorda i cronometri sportivi professionali.

Dettagli Tecnici

Utilizza requestAnimationFrame per aggiornamenti fluidi a 60fps con precisione al centesimo tramite performance.now(). L'interfaccia si adatta automaticamente alla dimensione dello schermo grazie a clamp() CSS. Font custom: League Gothic per il timer principale, Koulen per i pulsanti, Mitr per le label.

Sfide Implementative

  • Precisione temporale: uso di performance.now() invece di setInterval per evitare drift nel conteggio
  • Layout responsivo: tipografia fluida che scala da mobile a monitor di grandi dimensioni mantenendo proporzioni perfette

Z-Tutorial

GitHub ↗

Hub di tutorial interattive per studenti della classe 4IB dell'ITIS C. Zuccante di Mestre: JavaScript, reti, algoritmi e altro.

PHP Docker Nginx HTML/CSS/JS

Panoramica

Piattaforma educativa creata per gli studenti dell'ITIS Zuccante. Offre tutorial interattivi su molteplici argomenti del curriculum informatico, con un'interfaccia moderna e dark theme ottimizzata per la leggibilità del codice.

Contenuti

  • JavaScript: import script, eventi, DOM, Promise, Fetch API e quiz finale (6 pagine)
  • Cisco Packet Tracer: topologia, switch, router e configurazioni di rete (4 pagine)
  • JavaFX con Maven: setup IDE, struttura Maven, run/debug e packaging (7 pagine)
  • Grafi e Algoritmi: BFS, DFS, Dijkstra, Bellman-Ford, Prim, Kruskal con animazioni interattive
  • Analisi Matematica: teoremi di Rolle, Lagrange, De L'Hôpital, flessi e problemi di max/min

Sfide Implementative

  • Interattività: animazioni step-by-step per gli algoritmi sui grafi con tabelle di traccia in tempo reale
  • Router PHP custom: architettura ispirata ad actv-live, containerizzata con Docker Compose (Nginx + PHP-FPM)
  • Design tipografico: combinazione di Space Mono (heading), JetBrains Mono (codice) e DM Sans (corpo) per leggibilità ottimale
